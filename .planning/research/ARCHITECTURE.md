# Architecture research

Separate models, registry/event store, template registry, safe filesystem writes, detector, policy, SDK, monitor adapters, CLI, and reports. Monitors emit a common immutable event contract through an EventSink protocol. Registry-backed matching correlates exact unique tokens. SQLite commits creation metadata and CREATE together. Cooperative observations carry current process and run identity; kernel inotify events carry no PID. Keep health events for dropped coverage. Never persist full payloads, headers, argv or environment data.

Source: https://man7.org/linux/man-pages/man7/inotify.7.html
