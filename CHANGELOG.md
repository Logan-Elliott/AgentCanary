# Changelog

## 0.1.0

- Eight built-in synthetic artifact types, inert custom templates, and safe workspace profiles.
- Private SQLite registry and ordered creation/access/propagation/transmission evidence.
- Linux inotify snapshot monitoring and cooperative read, copy, tool, model and embedding observations.
- Bounded loopback HTTP inspection with no forwarding, explicit parsing diagnostics and unknown client PID.
- Retained allowlist/ignore annotations and text, JSON and JSONL reports.
- Installed end-to-end demo using real local subprocesses and HTTP, with failure and shutdown coverage.
- Linux/Python 3.11+ package, architecture and threat-model documentation, examples and local release verification.

This initial release observes configured boundaries. It does not provide system-wide egress enforcement, transparent TLS inspection or tamper-resistant evidence.
